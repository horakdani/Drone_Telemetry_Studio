Features

Everything you need for a telemetry overlay. Nothing you don't.

Built for pilots who want their flight data in the shot without paying for a subscription, uploading gigabytes, or fighting a video editor.

Accurate motion data

Haversine distance over ≥0.5 s windows, GPS-jump rejection and time-based smoothing give a speed readout you can trust.

Live route map

A fixed mini-map frames the whole flight: full path, path so far, start point, drone marker and a north arrow. OpenStreetMap background or fully offline cinematic style.

Frame-accurate preview

Scrub the timeline and see the real video frame with the HUD on top. Nudge the telemetry sync by ±0.01 s until it lines up perfectly.

Hardware encoding

Detects h264_videotoolbox and hevc_videotoolbox on Apple Silicon, with libx264 / libx265 as software fallbacks.

Private by design

No account, no cloud, no telemetry about you. The only optional network use is map tiles, and one toggle turns that off.

Never touches originals

Exports always go to a new file. Cancelling stops FFmpeg cleanly and deletes the partial output. Audio and VFR timestamps are preserved.

The app

Pick a video. Tweak. Export.

The SRT next to your MP4 is paired automatically by file name. Every setting previews instantly.

  • Toggle any field: speed, altitude, GPS, date, time, heading, vertical speed, distance
  • Map controls: corner, dark / light / cinematic style, hide at start or end
  • Validation report: FPS, VFR, duration, audio track and GPS warnings up front
  • Progress and ETA while exporting, with one-click cancel
How it works

One FFmpeg pass. No giant temp files.

Instead of rendering a transparent intermediate video, the HUD is streamed as raw RGBA frames straight into the same FFmpeg process that encodes your output.

Parse

A tolerant, block-by-block DJI SRT parser handles BOMs, optional fields and malformed blocks.

Compute

Speed, heading, vertical speed and distance in SI units, with outlier rejection and smoothing.

Render

Pillow draws a 960×540 HUD + route map at 10 fps, independent of the video frame rate.

Compose

FFmpeg upscales the HUD with Lanczos and overlays it on the original 1080p/4K stream in a single pass.

Get started

Install in a minute

Requires macOS 13+ (Apple Silicon recommended) and FFmpeg from Homebrew.

Download the app

# 1. Install FFmpeg
brew install ffmpeg

# 2. Download the latest release, unzip,
#    right-click the app → Open

Builds are not notarized yet, so macOS asks for confirmation on first launch.

Run from source

brew install python ffmpeg
git clone https://github.com/horakdani/Telemetry_Overlay.git
cd Telemetry_Overlay
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
./scripts/run_dev.sh
FAQ

Questions

Where do I find the SRT file?

Enable Video Subtitles (sometimes called Video Caption) in the DJI Fly or DJI Pilot camera settings. The drone then writes a .SRT with the same name next to each .MP4 on the SD card.

Which drones are supported?

DJI drones that write the bracketed SRT format with [latitude: …] [longitude: …] [rel_alt: …] fields, as recorded by recent DJI Fly models. Older layouts such as GPS(lon, lat, alt) aren't supported yet. If your file doesn't parse, open an issue with a few SRT blocks so it can be added.

Is anything uploaded?

No. Video and telemetry are processed locally. With the OpenStreetMap background enabled, only the map tiles for your flight's bounding box are downloaded and cached. Switch to the offline map style to make zero network requests.

Does it work on Windows or Linux?

The core is plain Python + Qt + FFmpeg, so it largely runs elsewhere, but only macOS is tested and packaged today. Contributions are welcome.

Will it re-encode my video?

Yes, because burning in an overlay requires re-encoding. You choose the encoder (hardware or software) and quality. The original audio is copied without re-encoding.
